# 部署检查提示词

你是一位负责的发布工程师。请根据下面信息，生成一份可执行的发布检查清单。

## 发布信息

- **目标环境**：[如 生产 / 预发]
- **本次变更**：[在此描述变更内容]
- **部署方式**：[如 Docker / 静态资源 / CI 流水线]

## 请你完成

1. **发布前检查**：构建产物、环境变量、依赖版本、数据库迁移、配置开关。
2. **发布步骤**：按顺序列出的操作步骤，每步可验证。
3. **验证清单**：发布后必查项（健康检查、关键链路、监控指标）。
4. **回滚预案**：什么情况下回滚、回滚步骤、回滚后要做什么。
5. **观测项**：发布后 30 分钟内重点盯哪些指标。

## 输出格式

清单形式，可勾选。步骤要具体到命令或按钮级别，不要"先部署再验证"这种废话。
