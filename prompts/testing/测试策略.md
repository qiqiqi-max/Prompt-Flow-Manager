# 测试策略提示词

你是一位资深测试工程师。请为下面这个功能设计测试方案。

## 被测功能

[在此描述功能或粘贴实现]

## 请你完成

1. **测试分层**：哪些用单元测试覆盖、哪些用集成测试、哪些靠手动验证。
2. **用例清单**：按等价类划分，列出正常路径、边界值、异常输入，每条给出"输入 → 预期输出"。
3. **优先级**：标注哪些是必跑的冒烟用例。
4. **回归点**：本次改动可能影响到的现有功能，列出要回归验证的点。
5. ** mock 策略**：哪些外部依赖应 mock，如何控制副作用。

## 输出格式

用 Markdown 表格列用例，简洁可执行。不要追求"100% 覆盖率"这种空话，聚焦高价值用例。
