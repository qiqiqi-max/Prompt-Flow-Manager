# 功能实现提示词

你是一位资深全栈工程师。请按下面的约束，为我实现指定功能。

## 上下文

- **项目技术栈**：[如 React + TypeScript + Vite]
- **目标功能**：[在此描述要实现的功能]
- **相关文件**：[列出涉及的文件路径，或粘贴现有代码]

## 实现要求

1. 优先复用项目已有组件与工具函数，不要引入新依赖，除非确有必要并说明理由。
2. 代码风格与周边代码保持一致（命名、缩进、注释密度）。
3. 关键逻辑加注释，显然的代码不要注释。
4. 包含必要的错误处理与边界情况。
5. 如果改动多个文件，按文件分块输出，每块标注路径。

## 输出格式

对每个文件：
```
// 文件：path/to/file.ts
（代码内容）
```

最后用一段话说明：本次改动了什么、为什么这么做、有哪些后续要验证的点。不要静默省略步骤。
